# WAVE CROWN 実艇シミュレーター仕様台帳

このディレクトリは、公開中のゲーム版とは独立した実艇再現用の開発系統です。
確認できていない値を事実として扱わず、`CONFIRMED`、`MEASURED`、`PROVISIONAL`に分けます。

## CONFIRMED

- 操作は右手ハンドル、左手スロットルレバー。
- 舵ではなく、2本のワイヤーでモーター本体とプロペラの向きを変える。
- 基本ターンはレバーを放して減速し、ハンドルを切り、旋回しながら徐々にレバーを握り、直線へ向いたらハンドルを戻す。
- 6艇はファンファーレとともにピットアウトする。
- 待機行動では2マークと小回り防止ブイを左回りする。
- 有効スタートは0.00秒以上1.00秒未満。
- 1周600mを3周、合計1,800m。
- 2つのターンマーク間は300mで、各マークを左回りする。
- 先頭艇のゴールから30秒以内に後続艇もゴールしなければならない。
- スタートは艇首がラインを過ぎた時、ゴールは艇の一部がラインに達した時に判定する。
- 最高速度は約80km/h。
- YM-730型ボートは全長2.895m、全幅1.316m、質量68kg以上70kg未満。
- 300型モーターは水冷2サイクル直列2気筒、396.9cc。
- S1-改型プロペラは直径187mm、ピッチ215mm、質量373±1g。

## MEASURED

現時点では未登録。公式艇内映像をフレーム解析し、次を測定してから登録する。

- 直進から最大操舵までのハンドル回転数
- ハンドル回転数とモーター偏向角の比率
- 通常ターンの初動、最大操舵、戻しの時間
- スロットルを落とす時間と当てレバーの時間
- 0–80km/h加速時間とレバーオフ時の減速曲線
- 1マーク、2マークの旋回所要時間と旋回半径

## PROVISIONAL

操作・計測系を先に検証するための暫定値。映像測定後に必ず置換する。

- 直進から最大操舵まで: 1.75回転
- モーター最大偏向角: ±30度
- 選手質量: 52kg
- モーター等搭載質量: 41kg
- 推進効率、抗力、旋回半径、ヨー応答

## 第1段階の合格条件

1. 艇はスロットル0%で静止状態を維持する。
2. 左レバーは0–100%を連続入力でき、放すと0%へ戻る。
3. 右ハンドルは円周ジェスチャーを累積し、複数回転を入力できる。
4. ハンドル中央では直進し、低速では旋回力が小さく、高速では旋回する。
5. 全開で約80km/hへ収束し、レバーを放すと水の抵抗で減速する。
6. 速度、rpm、スロットル、ハンドル回転、モーター角、艇首角、位置を表示する。
7. 上記を決定論的な自動テストで反復できる。

## 第2段階の合格条件

1. ファンファーレ前は6艇すべてピットで静止している。
2. ファンファーレ前のピット離れを受理しない。
3. 6艇のピット離れ後に待機行動・進入コース決定へ移る。
4. 待機行動中のモーター停止禁止を違反として判定できる。
5. 有効スタートを `0.00 <= ST < 1.00秒` とする。
6. `ST < 0.00秒` はF、`ST >= 1.00秒` はLとする。
7. 1マーク→2マークを3回通過した後だけゴールを受理する。
8. 公称距離を600m×3周＝1,800mとする。
9. ターンマーク間300mと、全マーク左回りを判定する。
10. 先頭艇ゴール後30秒の制限時間を判定する。

現在のピット離れからスタートまでの`100秒`は映像観測由来の`PROVISIONAL`であり、
公式の固定値として扱わない。一次資料または複数映像の計測データで変動幅を確定するまで設定可能値にする。
