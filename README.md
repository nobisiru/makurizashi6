# WAVE CROWN

スマートフォンのブラウザで遊べる、オリジナルの水上モータースポーツ育成ゲームです。

## 現在の実装

- ファンファーレ後、6艇が停止中のピットから一斉にピット離れ
- 小回り防止ブイ、待機行動、進入コース選択、助走距離の調整
- 大時計0.00〜0.99秒で通過するフライングスタート（F／L判定あり）
- 1マーク→2マークを反時計回りに3周する1,800mレース
- 左手の連続スロットルレバーと、右手の円形ハンドルを使う同時操作
- 直進位置からターン側へハンドルを360度（1.00回転）回し、出口で中央へ戻す旋回操作
- レバー開度、エンジン応答、速度二乗に比例する水の抗力、操舵抵抗による連続的な加減速
- 現在速度からスタートライン到達時刻を予測するスタートアシスト
- 重量バランスとパーツによるマシン整備
- AI艇、周回・順位・速度表示
- 低い斜め後方から艇を追うチェイスカメラ
- 右上小窓の選手一人称・艇首カメラ
- 前走艇の引き波による減速、画面振動、警告表示
- 他艇への接近・接触による失速とライン変更
- マーク手前でレバーを放し、360度まで左へ回し、当てレバーから出口で再加速するターン
- 競技順序を保つ28秒のQUICK CLOCKと、100秒の検証用REAL CLOCK
- ゴール後の順位、ST、賞金、ファン獲得表示
- 端末内への整備内容保存
- 正常スタート、フライング、出遅れ、3周完走を検査するランタイムテスト

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「レースへ出場」から出走表を確認します。
3. ファンファーレ後、左のスロットルレバーを上へ握ってピット離れします。
4. 待機行動中に右のハンドルで進入コースを選び、レバー開度で助走を調整します。
5. 大時計の0.00〜0.99秒でスタートラインを通過します。
6. 1・2マーク手前でレバーを放し、ハンドルを左へ360度回します。当てレバーを入れ、出口で中央へ戻して3周します。

## リアリティとゲーム化の境界

- 競技の順序、スタート判定、3周1,800m、ターンマーク間300m、最高速約80km/hはリアル側の固定条件です。
- 360度操舵はユーザー合意による暫定仕様で、実艇映像の追加計測後に再校正できます。
- QUICK CLOCK、ターン目標表示、スタート予測、ラインスコアは遊びやすさのための明示的なゲーム化です。
- 実艇モデルの確認値・暫定値・合格条件は `simulator/spec.md` に分離して記録しています。
