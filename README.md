# WAVE CROWN

スマートフォンのブラウザで遊べる、オリジナルの水上モータースポーツ育成ゲームです。

## 現在の実装

- ファンファーレ後、6艇が停止中のピットから一斉にピット離れ
- 小回り防止ブイ、待機行動、進入コース選択、助走距離の調整
- 大時計0.00〜0.99秒で通過するフライングスタート（F／L判定あり）
- 1マーク→2マークを反時計回りに3周する1,800mレース
- 押している間だけ効くアクセル／減速ペダルと、同時操作できる左右ステアリング
- 重量バランスとパーツによるマシン整備
- AI艇、周回・順位・速度表示
- 低い斜め後方から艇を追うチェイスカメラ
- 右上小窓の選手一人称・艇首カメラ
- 前走艇の引き波による減速、画面振動、警告表示
- マーク手前の減速、旋回中の左操作、出口での再加速
- ゴール後の順位、ST、賞金、ファン獲得表示
- 端末内への整備内容保存

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「レースへ出場」から出走表を確認します。
3. ファンファーレ後、アクセルを押し続けてピット離れします。
4. 待機行動中に左右で進入コースを選び、加減速で助走を調整します。
5. 大時計の0.00〜0.99秒でスタートラインを通過します。
6. 1・2マーク手前で減速し、左を押しながらアクセルを戻して3周します。
