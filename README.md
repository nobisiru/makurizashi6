# WAVE CROWN

スマートフォンのブラウザで遊べる、オリジナルの水上モータースポーツ育成ゲームです。

## 現在の実装

- 架空選手6艇による3周レース
- タップ式スロットルとイン／アウトの進路操作
- 重量バランスとパーツによるマシン整備
- AI艇、周回・順位・速度表示
- ゴール後の順位、賞金、ファン獲得表示
- 端末内への整備内容保存

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「レースへ出場」から出走表を確認します。
3. 「GO」の後にスロットルを1回タップします。
4. 左右ボタンを押して、旋回中の走行ラインを調整します。
